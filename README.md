# Greenhouse Image Processing Repository

This repository contains the implementation of a lightweight image processing system for plant health monitoring and growth estimation in low-cost automated greenhouse environments.

## Folder Structure

```
/greenhouse-image-processing
├─ code/                  # Python scripts
├─ datasets/              # Images (placeholders)
├─ models/                # Trained CNN model placeholder
├─ results/               # Evaluation outputs
├─ requirements.txt       # Python dependencies
└─ README.md
```

## Installation
```bash
pip install -r requirements.txt
```

## Usage
Run scripts in code/ as needed.
